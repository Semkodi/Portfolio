## ✨ Technische Highlights

- **🕹️ Cinematic 3D Orbit Workspace (Three.js):** 5 interaktive 3D-Code-Module mit Orbit-Rotation, Tiefenwirkung und dynamischer Parallax-Kippung bei Mausbewegung.
- **🔊 Web Audio API Sound-Engine:** Haptisches, mechanisches Sound-Feedback bei Navigation, Tastenanschlägen und Befehlsausführung (inkl. Stummschaltung).
- **🏛️ 4-Schichten Architektur-Blueprint:** Interaktive axonometrische Darstellung der Systemarchitektur (REST-APIs $\leftrightarrow$ PostgreSQL Datenbank $\leftrightarrow$ Java Spring Boot Logik $\leftrightarrow$ React Frontend).
- **🪪 Interaktive 3D Developer ID Card:** Entwickler-Ausweis mit Parallax-Tilt, Koordinaten und aktuellem Verfügbarkeits-Status.
- **📱 Mobile-First & Responsiv:** Flüssiger, nahtloser Dokumentenfluss auf Smartphones (iPhone, Pixel) und 4K-Desktop-Monitoren ohne Scroll-Fallen oder Clipping.
- **🛡️ Unsichtbarer Spam- & Bot-Schutz:** Kontaktformular mit Honeypot-Trap, Time-Gate (> 2,2s Ausfüllzeit) und verschleierter E-Mail-Generierung gegen Web-Scraper.
- **⚡ DSGVO & Performance:** 100 % lokales Asset-Hosting (keine Google Fonts-CDNs), optimierte WebP/AVIF-Grafiken, Sub-Sekunden-Ladezeiten.

## 💻 Lokale Entwicklung

```bash
# 1. Repository klonen
git clone https://github.com/Semkodi/Portfolio.git
cd Portfolio

# 2. Abhängigkeiten installieren
npm install

# 3. Lokalen Entwicklungsserver starten (Standard: Port 3000)
npm run dev

# 4. Typen und Codequalität prüfen
npm run lint

# 5. Produktions-Build erstellen
npm run build
```
